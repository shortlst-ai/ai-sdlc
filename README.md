# ai-sdlc

An AI-native software factory for the whole development lifecycle, built as a Claude Code plugin named `sdlc`.

Status: design stage. Nothing is built yet.

The factory moves each change through committed artifacts (`intent.md`, `spec.md`, `plan.md`, then code and evidence), so Git holds the state, the audit trail, and the resume point. A plugin makes the right path easy, the repo keeps it reviewable, and CI with branch protection enforces it.
